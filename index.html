コマンドログ・アナライザー

サーバーコンソールログを読み込み、issued server command: を目印にコマンドの使用率とプレイヤーの利用状況を可視化します。すべてブラウザ内で処理され、ログがどこかに送信されることはありません。

01ログファイル

ここにログファイルをドロップ、またはクリックして選択

.log / .txt / .csv 形式に対応（大容量ファイルもストリーミング処理で安全に解析します）

読み込み中... 0%

02解析モード
